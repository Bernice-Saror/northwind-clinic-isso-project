# 8. Plan of Action and Milestones (POA&M)

All items start as Open. Dates are targets for the fictional clinic.

| ID | Risk | Action | Owner | Milestones | Due date | Priority | Status |
|---|---|---|---|---|---|---|---|
| 1 | R1 | Add a “we never ask for your code” warning to every login screen, reminder, and message, and give patients a simple scam-awareness leaflet | IT admin (messages), ISSO (leaflet content) | Wording approved, messages updated, leaflet handed out at visits | 2026-12-15 | High | Open |
| 2 | R4 | Evaluate an optional authenticator app or face verification for patients who can use it | ISSO | Options compared, decision written, pilot if approved | 2027-03-31 | Moderate | Open |
| 3 | R3 | Produce a monthly report of patient file opens with no matching appointment or treatment link | IT admin (report), ISSO (review) | Report built, first review done, follow-up process written | 2027-01-31 | High | Open |
| 4 | R2 | Test the ambulance emergency line and forwarding every quarter, and confirm the dispatch agreement is signed | Clinic manager, IT assistant | Agreement signed, first test call, results recorded | 2026-12-31 | Moderate | Open |
| 5 | R5 | Run the first full backup restore test and a ransomware tabletop exercise | IT admin, ISSO | Restore test done, tabletop held, lessons recorded | 2026-12-15 | High | Open |
| 6 | R7 | Require a doctor or nurse to verify each lab result before release to the patient, and secure the lab connection | ISSO, clinic manager | Rule written, lab agreement signed, connection tested | 2027-01-31 | Moderate | Open |
| 7 | R8 | Set up on-call alerts, test after-hours escalation, and revisit outside monitoring once a year | IT admin, clinic manager | Alert rules live, first after-hours test, annual review date set | 2026-11-30 | Moderate | Open |

## Accepted residual risks

Signed off by the clinic manager (authorizing official): R6 (backups destroyed), R8 (night-time detection delay), and the weaker patient MFA method (R4), each with the compensating controls listed in the [risk assessment](07-risk-assessment.md).
